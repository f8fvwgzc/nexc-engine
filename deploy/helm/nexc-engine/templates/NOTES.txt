{{ if eq .Values.backend.dataAccessMode "ReadWriteOnce" -}}
The backend runs one replica on its ReadWriteOnce data volume, which attaches to one node: a
drain moves it. If that node fails, the pod stays Terminating and its replacement Pending until,
with the node really off, you run
  kubectl taint node <node> node.kubernetes.io/out-of-service=nodeshutdown:NoExecute
or force-delete it (kubectl delete pod <pod> --force --grace-period=0). More replicas, spread
across nodes, need backend.dataAccessMode=ReadWriteMany (docs/HA.md).
